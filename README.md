## 📌 Sobre o Projeto

A landing page **Sabor da Itália** foi desenvolvida para apresentar o cardápio, destaques, avaliações de clientes e diferenciais competitivos de uma pizzaria artesanal fictícia. 

O foco principal do projeto foi a criação de uma interface atraente, intuitiva e totalmente adaptável para dispositivos móveis, seguindo boas práticas de acessibilidade, semântica HTML e otimização CSS.

---

## 🚀 Funcionalidades

- 📱 **Design Totalmente Responsivo:** Layout fluido adaptado para smartphones, tablets e desktops.
- 🎨 **Estilização Moderna:** Paleta de cores inspirada na culinária italiana com tipografia limpa (*Google Fonts - Poppins*).
- 🍕 **Cardápio em Destaque:** Exibição de produtos com cards interativos e efeitos de *hover*.
- ⭐ **Sessão de Avaliações:** Depoimentos de clientes com sistema visual de pontuação.
- 📬 **Formulário de Newsletter:** Captura de e-mails para envio de ofertas e promoções no rodapé.
- 🔍 **Campo de Busca Visual:** Barra de pesquisa no cabeçalho.
- ♿ **Acessibilidade Básica:** Uso de tags semânticas, suporte a navegação via teclado com `:focus-visible` e atributos ARIA.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica do documento.
- **CSS3:**
  - Variáveis CSS (Custom Properties)
  - Grid & Flexbox para layouts
  - Animações e transições suaves
  - Media Queries para responsividade
  - Fontes externas do Google Fonts (`Poppins`)
